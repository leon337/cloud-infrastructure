# Histórico de Sessões

Registra evolução causal sem exigir leitura integral dos chats.

Cada sessão relevante deve conter: objetivo, estado inicial, ações, resultados, erros, decisões, autorizações, aprendizados, arquivos alterados, estado final e próximo passo.

O histórico não vence o estado atual; serve para explicar como e por que chegamos até ele.
